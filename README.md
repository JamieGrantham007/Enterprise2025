# ☕ Baldwin's Brews – Enterprise Village Website

A simple landing page created for **Enterprise Village 2025** to showcase Baldwin's Brews.  
The page uses a modern **grid-based background** with posters, overlaid with a **welcome message and contact button**.

---

## 🌟 Features

- 🎨 **Grid layout** background with 4 promotional posters  
- 🖋️ Clean and modern **Inter font** (Google Fonts)  
- 🖤 Dark theme with white text for contrast  
- 📬 **Contact button** that opens a mail client for pre-orders  
- 📱 Fully responsive and centered layout

## 🚀 How to Run

1. Clone or download the repo:  

   ```bash
   git clone https://github.com/<your-username>/Enterprise2025.git
   cd Enterprise2025
   ```

2. Open `index.html` in any browser (double-click it).  

3. (Optional) Host it on **GitHub Pages** to make it shareable:  
   - Go to **Settings > Pages** in your repo  
   - Select `main` branch, root folder, and save  
   - Your site will be live at:  
     ```
     https://<your-username>.github.io/Enterprise2025
     ```

## 💡 Customization Ideas

- Swap out the background poster images with updated branding or new products.  
- Change the overlay text in `.content` (`<h1>` and `<p>`) to match the event theme.  
- Update the **email link** to the appropriate contact address.  
- Add social media links under the button for more engagement.
